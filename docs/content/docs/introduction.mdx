Colbe is a community-based platform. It gives groups of people a place to talk, organize, and build something that feels like theirs, with channels, direct messages, and announcements in one place.

## Features

* **Guilds**: Create a guild, invite members, and run it with owners and admins.
* **Channels**: Keep every topic in its own place so nothing gets lost.
* **Direct messages**: Talk privately with anyone, away from the main channels.
* **Community page**: Owners and admins can post announcements right on the community page.
* **Quick start**: Register with just your email, then finish setup in onboarding.

...and more on the way.

***

## What is next

Colbe is growing. We are working on finishing the chat interface, public APIs, a developer hub with in-browser coding, and a native Windows app with a web PWA for older hardware.
