<Callout type="info">
  The Colbe application is not yet available to download. Installation steps will be added here as soon as it is.
</Callout>

<Steps>
  <Step>
    ### What is coming

    We are working on two ways to run Colbe on your device:

    * **Native Windows app**: built for modern Windows.
    * **Web PWA**: for older hardware, including legacy Windows.

    Neither is available yet. Both are planned.
  </Step>

  <Step>
    ### Use Colbe in the meantime

    You do not need to install anything to get started. [Sign in](/login) to Colbe from your browser and join or create a guild.
  </Step>

  <Step>
    ### Stay up to date

    We will announce downloads on the blog and in the changelog. Until then, read the [Community Guidelines](/legal/guidelines), or reach out through the [support page](/support) if you have questions.
  </Step>
</Steps>
